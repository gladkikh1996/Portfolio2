## Запуск

Проверенная версия — **Python 3.12.14**. Для запуска примеров достаточно стандартной библиотеки Python. Команды ниже выполняются из корня репозитория, если отдельно не указан переход в папку проекта.

```bash
python --version
python 01_basics/01_hello/Hello.py
python 02_collections/01_lists/list_task.py
python 04_oop/02_magic_methods/oop.py
```

Задание на условия последовательно запрашивает 13 значений: числа, время записи, возраст, оценку, название молока, тестовую строку пароля и год.

```bash
python 01_basics/05_conditions/conditional_statements.py
```

Для библиотечного проекта **нужно сначала перейти в его папку**: каталог книг читается по относительному пути `data/books.json`.

```bash
cd 05_projects/02_library_logging
python main.py
```

Пример выводит сценарий выдачи/возврата книг и создаёт `library.log` в текущей папке. Журнал дописывается при повторных запусках и исключён из Git. Состояние выдачи хранится в памяти между операциями одного запуска; JSON с исходным каталогом не перезаписывается. Вывод сообщений об отклонённых операциях — часть демонстрационного сценария.

Внутри каждой версии библиотеки сохранены оригинальные `.flake8`, `.pylintrc` и `requirements.txt` с инструментами линтинга. Они не нужны для обычного запуска. Установка этих закреплённых версий и прохождение линтеров при сборке портфолио не проверялись.

## Проверка и особенности исходных работ

На 26 октября 2026 года проверены:

- 37 импортированных файлов — совпадение SHA-256 с полученными исходниками;
- 27 Python-файлов — успешная проверка синтаксиса;
- 20 точек запуска — 18 завершились с кодом 0, две с исключениями ниже.

| Пример | Поведение при запуске всего файла |
|---|---|
| `data_types.py`, строка 11 | Присваивание элементу кортежа вызывает `TypeError`; дальнейшие блоки не выполняются. |
| `set_task.py`, строка 11 | `remove()` для отсутствующего элемента вызывает `KeyError`, в отличие от показанного перед ним `discard()`. Дальнейшие блоки не выполняются. |

Исходные решения перенесены без изменения логики. Успешный запуск не доказывает правильность всех упражнений: некоторые примеры содержат ограничения, перечисленные в [заметках о проверке](docs/verification.md). Случайные значения, даты, порядок элементов множеств и `id()` могут отличаться между запусками.
