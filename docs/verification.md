# Проверка исходных решений

Дата: 26 октября 2026 года. Среда: Windows, CPython 3.12.14.

## Что проверено

Сверены 20 каталогов работ и SHA-256 всех 37 импортированных файлов. Проверка синтаксиса всех 27 файлов `.py` прошла. Все 20 точек входа запускались отдельными процессами на копиях в служебной папке с ограничением времени; исходные файлы не изменились.

18 запусков завершились с кодом 0. Два исходных учебных примера завершились с кодом 1:

- [Типы данных](../01_basics/03_data_types/data_types.py), строка 11: `my_tuple[0] = [5]` → `TypeError`. Кортеж неизменяем.
- [Множества](../02_collections/03_sets/set_task.py), строка 11: `asia_set.remove("Вьетнам")` → `KeyError`. Перед этим в исходнике показана разница между `discard()` и `remove()`.

В обоих случаях более поздние блоки в том же файле при обычном полном запуске не выполняются. Для изучения их можно запускать отдельно в редакторе. При сборке коллекции эти примеры не переписывались.

Для [условий](../01_basics/05_conditions/conditional_statements.py) при проверке переданы 13 строк в таком порядке:


Это один сценарий ввода; все возможные ветвления не проверялись. Строка `example!123` — выдуманные данные учебного примера.

## Ограничения, видимые в исходниках

- [Переменные](../01_basics/02_variables/variables.py), строки 37–40: цепочка присваивания записывает один кортеж в `a`, `b` и `c`; затем печатаются строковые литералы `"a"`, `"b"`, `"c"`. Это не распаковка трёх значений.
- [Операции](../01_basics/04_operations/operations.py), строка 97: используется необъявленное имя `n`. При текущем значении `a = 5` до него не доходит вычисление из-за короткого замыкания `and`, поэтому пробный запуск успешен; изменение условия может вызвать `NameError`.
- [Исключения](../03_functions/05_exceptions/exceptions.py): импорт отсутствующего `recommendations_engine` находится внутри демонстрации обработки `ModuleNotFoundError`. Дополнительный пакет устанавливать не требуется.
- [Библиотека до логирования](../05_projects/01_library_linters/): при попытке выдать четвёртую книгу пользователю книга сначала помечается выданной, хотя операция отклоняется лимитом. В [следующей версии](../05_projects/02_library_logging/) её доступность восстанавливается; обе стадии оставлены для сравнения.
- Обе библиотеки читают `data/books.json` относительно текущей папки. Запуск из другой папки может завершиться с кодом 0, но сообщить, что каталог не найден. Повторный вызов загрузчика в одном процессе добавляет записи повторно.
- Большинство файлов исполняют демонстрационный код прямо при импорте. Это самостоятельные упражнения, а не библиотечные модули с гарантированным отсутствием побочных эффектов.
- Версия с логированием создаёт `library.log` уже при импорте настроек. Журнал дописывается, ротации нет. Обычный запуск Python также может создать `__pycache__`; эти файлы исключены из Git.

Пробные запуски не заменяют полную проверку заданий по условиям курса, функциональные тесты или линтинг. Оригинальные закреплённые зависимости линтеров не устанавливались. Другие версии Python не запускались.
