# Публикация на GitHub

Адрес репозитория для публикации: `gladkikh1996/Portfolio2`. Описание: «Учебные задания по Python для QA: коллекции, функции, ООП и библиотечный проект с логированием».

## Если работаешь с подготовленной локальной Git-папкой

Открой терминал в корне `python-qa-homework` и проверь состояние:

```bash
git status
git log -1 --oneline
```

Если первый коммит ещё не создан, укажи своё имя и адрес для авторства (можно GitHub noreply-email), затем создай коммит. Значения `YOUR_NAME` и `YOUR_EMAIL` нужно заменить своими; конфигурация применяется только к этому репозиторию.

```bash
git config user.name "YOUR_NAME"
git config user.email "YOUR_EMAIL"
git add .
git commit -m "Collect Python QA homework portfolio"
```

Если репозиторий ещё не создан, создай его пустым на GitHub без автоматически добавляемых README, `.gitignore` и LICENSE. Если `origin` ещё не настроен, выполни:

```bash
git remote add origin https://github.com/gladkikh1996/Portfolio2.git
git push -u origin main
```

Вход в GitHub выполняется обычным способом через установленный Git credential manager или другой настроенный способ авторизации. Данные входа не нужно вписывать в URL.

## Если используешь ZIP

В архив включены исходники и документация, без каталога `.git`. Распакуй архив, перейди в `python-qa-homework`, выполни `git init -b main`, затем шаги настройки авторства, создания первого коммита и подключения GitHub выше.

## После публикации

Открой README на GitHub и проверь переходы к папкам. Для резюме используй ссылку на репозиторий; как примеры кода подойдут библиотека с логированием и ООП-модель отеля. Известные особенности исходных учебных решений перечислены в [verification.md](verification.md).
